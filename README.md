# Customer_Behavior_Analysis

# Project Overview
This project is an end-to-end Customer Behavior Analysis System built using Python, PostgreSQL, and Power BI.
The goal of this project is to analyze customer purchasing patterns and generate actionable business insights through data cleaning, database querying, and interactive dashboards.

# Objectives
- Analyze customer purchasing behavior
- Identify high-revenue product categories
- Understand customer segmentation (age groups, spending patterns)
- Generate business insights using data visualization

# Tech Stack
- Python (Pandas, NumPy) – Data cleaning & preprocessing
- PostgreSQL – Data storage & SQL analysis
- SQL – Aggregations, JOIN, GROUP BY, filtering
- Power BI – Dashboard and visualization
- Jupyter Notebook – Development environment

# Project Workflow
1️- Data Cleaning (Python)

- Removed missing values
- Handled duplicates
- Formatted data types
- Performed preprocessing using Pandas

2️- Database Management (PostgreSQL)

- Created database and tables
- Loaded cleaned data into PostgreSQL
- Performed SQL queries for analysis

3️- Data Analysis (SQL)

Performed analysis such as:
- Category-wise revenue
- Customer age-group spending
- Purchase frequency
- Average transaction value

4️- Dashboard Creation (Power BI)

- Built interactive dashboard including:
- Revenue by Category
- Customer Distribution
- Sales Trends
- Key Performance Indicators (KPIs)

# Key Insights

- Identified top-performing product categories
- Analyzed spending behavior across age groups
- Detected high-value customer segments
- Generated insights for improving marketing strategy
